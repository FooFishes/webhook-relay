## HTTP 验证方式

脚本为每次运行创建独立临时 SQLite 文件，并启动真实 Rust 进程和本地飞书模拟服务。使用 Python 标准库独立计算 Apple 请求签名和飞书消息签名，验证实际 HTTP 输入输出与数据库状态。

主要覆盖：

- 概览鉴权、空数据、时间范围校验、超过 50 条记录的完整统计、图表与总数一致性、暂停队列、历史失败和关联查询。
- 适配器元数据、显式平台预览、通用回调路径、旧快照兼容、平台类型不可变。
- 多来源去重隔离、多目标分发、共用目标、独立启停、逐任务尝试记录和单规则转换失败隔离。
- 管理 API 鉴权，来源不存在返回 404，错误配置和旧版本更新被拒绝。
- 密钥写入、留空保留、引用约束和不回显。
- Apple 原始体验签、格式错误、体积限制、重复事件、并发重复事件、同一 ID 不同正文冲突。
- 消息预览、中文/引号/换行、缺失模板字段、模板失败留存。
- 飞书 HTTP 200 业务失败、HTTP 429、HTTP 200 限流业务码、5xx、非法响应和禁止重定向。
- 自动重试、手动重试、逐次发送记录、重启恢复和强制中断发送时的未知结果记录。
- 事件过滤、停用来源、队列记录持久化、恢复处理。
- 审计动作、配置前后元数据、分页筛选、敏感值不进入审计、数据库加密和审计更新触发器。
- 主密钥错误拒绝启动、同一 SQLite 数据库拒绝第二个进程。

详细报告在 `reports/http-verification.html` 和 `reports/http-verification.json`。该目录已被 Git 忽略，重新运行脚本即可生成。

## Docker 验证方式

1. Compose 配置可解析。

6. 根文件系统只读。
7. 管理 API 要求鉴权。
